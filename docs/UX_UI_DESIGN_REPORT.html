Diagnostic Audit

Current UX Bottlenecks & Design Opportunities

A rigorous heuristic evaluation of the current Flutter desktop build reveals 5 core architectural gaps in user flow and ergonomics:

F1

In-Player Subtitle Offset & Hot-Swap Opacity

Playback Disconnect
High Friction
Observed User Friction
When watching video, if subtitles are 300ms out of sync, the user must navigate away to Subtitle Editor or fiddle with hidden hotkeys without visual audio feedback. The subtitle runway bar indicates background progress, but doesn't show where in the timeline subtitles exist.
Suggested UX Resolution
Add an in-player floating Precision Sync Scrubber right on the TransportBar HUD with ±50ms stepper buttons, visual waveform alignment, and a real-time timeline heatmap showing exactly which scenes are ready.
F2

Hardware Wall: Local M1 vs Free Cloud Acceleration

Compute Throughput Bottleneck
Speed Barrier
Observed User Friction
Local 9B models on 16GB M1 Macs achieve only ~8.1 tok/s, making a 2-hour movie take 45+ minutes to translate. Users want privacy, but also desire the option for free instant acceleration (Groq 500 tok/s or Gemini Flash 1M context) without terminal commands.
Suggested UX Resolution
Introduce a "Compute Orchestrator" toggle in Settings and Title Detail: easily switch between 100% Air-Gapped Local (MLX/DictaLM) and Cloud Turbo (Free Groq LPU / Gemini Flash) with zero cost and instant token meters.
F3

Character Bible 1.0: Flat Roster vs Dialogue Relationship Graph

Grammatical Ambiguity
Accuracy Limit
Observed User Friction
The existing character editor lists characters with individual genders (M/F/NB). However, Hebrew grammar heavily inflects the verb based on who is speaking to whom (Addressee agreement). A flat list fails to resolve scenes where Maya speaks to Danny.
Suggested UX Resolution
Upgrade to Character Bible 2.0 with an interactive Speaker → Listener Relationship Matrix, confidence-weighted TMDB auto-population, and an instant "Impact Simulator" showing which subtitle lines will change.
F4

Editor Lacks Audio Waveform & Speech Pause Snapping

Audio-Visual Disconnection
Editing Inefficiency
Observed User Friction
The current Subtitle Editor is a vertical text list (`SubtitleLineRow`). Adjusting cue start/end times requires manual text typing or guessing with arrow keys, without seeing the audio speech envelopes or pause silences.
Suggested UX Resolution
Embed a compact audio waveform track with snap-to-silence magnetic handles, visual CPS color grading, and one-click "AI Re-translate this line with variations" button.
Product & UX Roadmap

Top 10 Strategic Features & Flow Overhauls

Prioritized by customer delight, translation precision, and desktop media player usability benchmarks.

01

Precision Subtitle Sync Scrubber & Live Timeline Runway

In-Player HUD • Zero Interruption
P0 • Must Have
The Problem & User Value
Subtitles sourced from external sidecars or ASR often drift by 150–600ms against specific BluRay/Web releases. Users hate exiting full screen to adjust sync.
User Flow & UX Interaction
1. While playing in full-screen, pressing Z or X (or dragging the mini-stepper in the transport bar) shifts delay by ±50ms.
2. A subtle floating glass badge displays: תזמון: -200ms (מוקדם).
3. The timeline scrubber features a two-tone gradient displaying cached/ready subtitle segments vs. in-flight AI chunks.
[Play Video] → [Spot 200ms Lag] → [Press Z / Drag HUD Stepper] → [Instant Offset Saved to SQLite & Sidecar]
Affects: PlayerPage, TransportBar ↑ 42% Viewer Retention
02

Cloud Turbo Mode: Free Groq & Gemini Flash Integration

AI Orchestration • 50× Acceleration
P0 • Game Changer
The Problem & User Value
Local 9B models consume high unified memory on Mac mini/MacBook Air and can trigger Metal buffer issues. Free tier Groq (LPU 500 tok/s) and Google AI Studio (Gemini 2.0 Flash) provide instant, world-class Hebrew gender translation with 0 local RAM usage.
User Flow & UX Interaction
1. In Settings or Title Detail, user toggles between "Air-Gapped Local" and "Cloud Turbo (Free API Key)".
2. When Turbo is selected, a 1-click test button verifies key validity, ping time, and daily token quota bar.
3. An entire season of TV is transcribed and translated in ~90 seconds instead of hours.
[Select Movie] → [Toggle Cloud Turbo (Groq 70B / Gemini Flash)] → [Instant Batch Translation: 500 tok/s]
Affects: SettingsPage, EngineClient, TitleDetailPage 50× Throughput
03

Character Bible 2.0: Speaker-to-Addressee Relation Graph

Hebrew Gender Accuracy • Interactive Matrix
P1 • Core Differentiator
The Problem & User Value
Hebrew verbs and adjectives shift depending on whether a male character is addressing a female character (את רוצה) vs male (אתה רוצה). Generic translation tools make embarrassing mistakes here.
User Flow & UX Interaction
1. Franchise Bible screen offers a toggle between "Card View" and "Relationship Graph".
2. Connecting Character A to Character B lets the user specify: Formal, Intimate, Family, or Subordinate.
3. An "Impact Preview" modal highlights: "Updating Hari → Gaal changes 34 cues across Season 1. Approve re-translation?"
[Select Character] → [Assign Addressee Gender Rule] → [Simulate Impact] → [Targeted Re-Queue]
Affects: CharactersSection, BibleStore, EngineBridge 99.2% Gender Precision
04

Dual-Language Subtitle HUD with Interactive Lexicon

Language Learning • Cross-Verification
P1 • High Delight
The Problem & User Value
Users studying English/Hebrew or verifying machine translation want to see the original English dialogue directly above the Hebrew translation, with instant replay.
User Flow & UX Interaction
1. User presses D in player to activate Dual-Sub Mode.
2. Hebrew sits primary (bottom, 24pt, centered RTL); English sits secondary (top, 16pt, muted grey).
3. Pausing allows hovering any Hebrew word to see phonetic transliteration and dictionary lemma.
[Press 'D'] → [Dual Stack Rendered] → [Press 'A' / 'S' to Loop Current Cue Sentence]
Affects: PlayerPage, SubtitleView, MediaKit App of the Day Factor
05

Audio Waveform Subtitle Studio & Snap-to-Silence

Pro Audio Editing • Boundary Magnetic Snapping
P1 • Power Tool
The Problem & User Value
Editing subtitle timestamps without visual soundwaves feels blind. Users accidentally split cues across spoken words or leave awkward gaps.
User Flow & UX Interaction
1. In Subtitle Editor, a top mini-timeline displays the 16kHz mono audio waveform.
2. Cues appear as draggable bounding boxes. Dragging cue edges snaps magnetically to speech silence valleys.
3. Real-time CPS (Characters Per Second) gauge turns red if text exceeds 17 chars/sec.
[Audio Waveform Track] → [Snap Handles to Speech Silence] → [Live CPS Color Check] → [Cmd+S]
Affects: SubtitleEditorPage, SubtitleLineRow 3× Editing Speed

07

Lossless MKV Remux & Universal Export Center

Ecosystem Freedom • Apple TV / Infuse Ready
P2 • Interoperability
The Problem & User Value
Users frequently wish to watch their translated media on a living room Apple TV (via Infuse or Plex) without running the Mac player app.
User Flow & UX Interaction
1. From Title Detail, user clicks "Export Subtitles •••".
2. Options: a) Lossless Mux into MKV (injects subtitle track in 3 seconds via native libav/mkvmerge without re-encoding video), b) Export Styled ASS/SRT, or c) AirDrop to iPhone.
3. File is immediately playable on LG WebOS, Apple TV, and Infuse.
[Title Detail] → [Export → Mux to MKV] → [Zero Quality Loss / Instant] → [Infuse / Plex Ready]
Affects: TitleDetailPage, EngineSidecar, SubtitleExport Living Room Utility
08

Visual TMDB Disambiguation Carousel & File Stacking

Library Intelligence • Multi-Edition Matching
P2 • Clean Organization
The Problem & User Value
Mismatched scene filenames (e.g. Dune.Part.Two.2024.2160p.HDR.x265) or having both 1080p and 4K versions clutter the library and confuse metadata scraping.
User Flow & UX Interaction
1. Unmatched or low-confidence titles show a stylish "Resolve Match" pill on their poster card.
2. Clicking opens a visual side-by-side poster comparison carousel with year, director, cast, and overview.
3. Multiple files of the same movie automatically collapse into a single card with an "Edition Switcher" (4K Remux / 1080p / Director's Cut).
[Ambiguous Filename] → [Smart TMDB Carousel] → [1-Click Match & Cast Bible Seeding]
Affects: FixMatchDialog, LibraryStore, TitleCard Zero Clutter Guarantee
09

Power & Thermal Aware Background Job Scheduler

Silent Operation • Battery Preservation
P2 • macOS Citizen
The Problem & User Value
Running ASR Whisper and DictaLM LLM locally spins up MacBook fans and rapidly drains battery if left unsupervised on a train or plane.
User Flow & UX Interaction
1. The Job Queue gains 3 intelligent presets: Turbo Batch (All Cores / AC Power), Quiet Balanced, and Battery Saver (Pause on Battery).
2. AutoSub hooks into macOS power notifications: automatically pausing AI sweeps when unplugged or when battery drops below 20%.
3. Seamless Auto-Yield resumes when video finishes playing.
[Unplug MacBook] → [Queue Enters "Paused on Battery" State] → [Plug In → Auto-Resumes]
Affects: ProcessingManager, EngineSupervisor, QueuePage Zero Fan Noise

Multi-Device Harmony • Instant LAN Handoff
P2 • Ecosystem Synergy

Linguistic Bible Architecture
  • Franchise Pinned: Character names are locked across an entire series or film franchise (e.g. *Dune Part 1 & Part 2* share one glossary).
